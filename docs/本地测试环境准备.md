## 启动、检查与停止

在项目根目录执行：

```bash
python3 scripts/local-stack.py start
python3 scripts/local-stack.py status
python3 scripts/local-stack.py stop
```

停止保留全部数据卷；脚本只管理它记录的服务进程，并通过进程启动时间防止误杀复用的 PID。启动会检查数据库并按迁移记录跳过已执行的迁移。已经实跑一次完整停止/启动，复用原数据卷后所有服务恢复正常。本机工具位于 `/home/fufu/workspace/.local-runtime`，这份启动入口针对当前准备好的工作区。

当前代理已通过用户设置的 Docker socket ACL 获得访问权限。若 Docker 重启后出现 permission denied，可在宿主机普通终端重新执行：

```bash
sudo setfacl -m u:fufu:rw /var/run/docker.sock
```

当前代理的 no-new-privileges 限制使 `sg docker` 无法在原会话切组；本轮已实际验证此限制。

## 模型与真实向量

默认生成模型为 `models/Qwen3-4B-Instruct-2507`，8192上下文上限、最多4个并行序列、显存预算0.80、纯文本eager模式。关闭请求内容日志与用量遥测。文档和推理都留在本机。

Embedding使用本地 `models/bge-small-zh-v1.5`，CPU推理、CLS pooling后L2归一化，512维，Milvus集合 `rag_bge_small_zh_v1`，COSINE索引。文档与query共用模型，query添加中文检索指令；正式模式发生错误时不会回退成伪向量。

文档在embedding服务使用同一tokenizer切成384 token、48 token重叠的片段；embedding接口拒绝超过512 token的输入。中文/英文混排长文本测试产生19个片段，全部成功生成512维向量。批次最多32条。

`rag.embedding.mode=fake` 保留旧演示能力；当前本地配置显式使用 `http` 正式模式。切换embedding模型必须同时核对维度、分块和集合，不能混用原128维伪向量。

9B FP8仍作为可选模式：先停止当前服务，再以以下环境变量启动同一管理脚本，可以只替换生成模型：

```bash
python3 scripts/local-stack.py stop
MODEL_PATH=/home/fufu/workspace/models/Qwen3.5-9B-FP8 \
MAX_MODEL_LEN=4096 MAX_NUM_SEQS=1 GPU_MEMORY_UTILIZATION=0.90 \
python3 scripts/local-stack.py start
```

9B前一轮在纯文本、4096上限、单并发、关闭thinking配置下成功完成6次请求，其中最长3417输入token。观察到整卡占用最高14268 MiB，包含桌面进程，不是持续采样得到的峰值。它尚未完成本轮完整RAG的持续负载与质量对比，因此默认仍用4B。

## 容器与新库初始化

`docker-compose.local.yml` 使用独立 rag-local 卷，持久化 MariaDB、Redis、MinIO、Milvus、etcd。所有映射到宿主机的端口只绑定127.0.0.1。

Docker daemon直连DockerHub超时，故本轮通过用户代理和官方 crane 下载公开镜像，再 `docker load` 导入。当前所需镜像均已保存在本机。

原项目指定的MinIO镜像已无法公开拉取。本轮从 [MinIO官方固定源码发布](https://github.com/minio/minio/releases/tag/RELEASE.2025-10-15T17-29-55Z)编译静态二进制，封装为本地scratch镜像 `rag-local/minio:RELEASE.2025-10-15T17-29-55Z`，未使用第三方替代镜像。源码归档SHA256为 `be6d0bd3696c3a13a35f02d3a0280b64319c67918b4501c5c3d87f96d000085c`。

重建此镜像可运行 `python3 scripts/prepare-local-minio.py`；该脚本已实际重建成功。日志显示版本为DEVELOPMENT.GOGET，因为未注入上游发布构建的版本ldflags；源码来源与固定发布标签以本记录和校验摘要为准。

基础初始化沿用项目明确列出的脚本，之后执行 `scripts/migrate-local-db.py` 中审核过的14项后续迁移；记录写入 `rag_local_schema_migration`，保存名称和SHA256。已经验证重跑会跳过同摘要迁移。禁止直接遍历执行整个sql目录。

`sql/local_rag_acceptance.sql` 只用于本次专用新测试库，创建/设置上述隔离测试身份，不应对既有业务库执行。

已通过：

- 登录、公开TXT上传、秘密级TXT上传、中文扫描PDF上传；MariaDB元数据、MinIO原件和Milvus切块均成功写入。

- 组成员关系撤销、文档停用后，后续请求立刻过滤对应秘密内容；测试后恢复演示成员关系和文档状态。

- 1/2/4路完整RAG短请求约0.4至0.7秒；跨四种身份的8路突发请求约0.31至0.60秒。
